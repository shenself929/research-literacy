## 2. Setting

| 字段 | 内容 | 证据/备注 |
|---|---|---|
| 研究对象 | | |
| 任务 | 预测 / 解释 / 优化 / 控制 / 构建 | |
| 输入 | 数据类型、规模、获取方式 | |
| 输出 | 结果形式、评价对象 | |
| 约束 | 伦理、成本、时间、可用设备 | |
| 评价指标 | 主要指标 + 次要指标 | |

**一句话 setting**：

```text
在【对象】上，给定【输入】和【约束】，产出【输出】；用【指标】评价。
```

## 4. 课题评估（P13–P15）

| 维度 | 判断 | 依据 |
|---|---|---|
| 发展空间 | 大 / 中 / 小 | |
| 竞争 | 激烈 / 一般 / 少 | 近三年同题团队数、标准方案成熟度 |
| 能力匹配 | 过难 / 匹配 / 过简单 | 需要的技能 vs 现有技能 |
| 影响 | 大 / 中 / 小 | 谁会用、解决什么后果 |
| 任务定义 | well-defined / ill-defined | 输入输出是否可操作化 |
| 风险等级 | 低 / 中 / 高 | 技术风险 + 资源风险 |
| 是否 Aim High | 是 / 否 | 是否接近能力极限 |

**结论**：做 / 暂缓 / 换题 / 先补视野。写一句理由。

### 示例（只示范粒度）

| 字段 | 示例 |
|---|---|
| 研究对象 | 某类免疫细胞在肿瘤微环境中的状态转换 |
| 输入 | 单细胞转录组 + 空间位置 |
| 输出 | 状态标签与转换概率 |
| 约束 | 样本量 30 例，伦理审批已过 |
| 指标 | 标签一致性、预测 AUROC、机制可检验性 |
| baseline | 现有聚类 + 标记基因注释 |
| failure case | 稀有状态被合并，跨样本不稳定 |
| challenge | 状态是连续的，硬聚类丢失过渡态 |
| 风险 | 中：数据量够但验证实验贵 |
